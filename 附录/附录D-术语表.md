# 附录 D 术语表

> 本附录分两部分:**D.1 CUDA 与 CANN 术语双向对照表**,供在两套软件栈之间切换的读者快速定位"这个词在另一边叫什么";**D.2 算法术语的资源含义速查表**,供 Infra 侧读者在会议中听到算法术语时,立刻知道它对应哪一笔资源开销。
>
> 对照关系描述的是**职责位置的对应**,不代表实现机制相同——两边是两套完整并行的世界,不是方言关系(立场见 [§5.3](../第一部分-基础与心智模型/第05章-CUDA、CANN与加速器软件栈.md#53-cann-与昇腾软件栈两套完整并行的世界))。术语表不含版本号与 API 签名,那些内容见附录 C。

## D.1 CUDA 与 CANN 术语双向对照表

### D.1.1 硬件与执行模型

| CUDA / NVIDIA 侧 | CANN / 昇腾侧 | 职责位置 | 对应程度与注意点 | 详见 |
|---|---|---|---|---|
| GPU | NPU(昇腾 AI 处理器) | 加速器整卡 | 架构范式不同:SIMT 通用并行 vs 多单元协同(达芬奇架构) | [§4.2](../第一部分-基础与心智模型/第04章-硬件第一性原理、架构范式与数值精度.md#42-加速器架构范式) |
| SM(Streaming Multiprocessor) | AI Core | 基本计算单元 | 内部结构差异大:SM 以标量/张量核并列,AI Core 以 Cube/Vector/Scalar 三单元协同 | [§5.1](../第一部分-基础与心智模型/第05章-CUDA、CANN与加速器软件栈.md#51-cuda-执行模型与软件栈) / [§5.3](../第一部分-基础与心智模型/第05章-CUDA、CANN与加速器软件栈.md#53-cann-与昇腾软件栈两套完整并行的世界) |
| Tensor Core | Cube 单元 | 矩阵乘加速单元 | 两者都是矩阵乘专用单元;精度支持谱系不同,需对照附录 A | [§4.2](../第一部分-基础与心智模型/第04章-硬件第一性原理、架构范式与数值精度.md#42-加速器架构范式) |
| CUDA Core(标量/向量运算) | Vector 单元 + Scalar 单元 | 非矩阵运算 | 昇腾把向量与标量职责显式分开,算子实现需分别调度 | [§5.3](../第一部分-基础与心智模型/第05章-CUDA、CANN与加速器软件栈.md#53-cann-与昇腾软件栈两套完整并行的世界) |
| warp(32 线程) | ——(无直接对应) | 调度最小粒度 | 昇腾执行模型不以 warp 组织,SIMT 直觉不可直接迁移 | [§5.1](../第一部分-基础与心智模型/第05章-CUDA、CANN与加速器软件栈.md#51-cuda-执行模型与软件栈) |
| 共享内存 / 寄存器 / L2 | Unified Buffer / L1 Buffer / L2 | 片上存储层级 | 层级都存在,但容量比例与搬运方式不同,影响算子分块策略 | [§5.3](../第一部分-基础与心智模型/第05章-CUDA、CANN与加速器软件栈.md#53-cann-与昇腾软件栈两套完整并行的世界) |
| HBM 显存 | HBM 显存 | 片外高带宽内存 | 物理形态一致;可用容量的预留扣除项不同 | [§4.1](../第一部分-基础与心智模型/第04章-硬件第一性原理、架构范式与数值精度.md#41-四个数字与物理约束) |
| NVLink / NVSwitch | HCCS | 卡间高速互联 | 拓扑组网方式不同,直接影响并行策略与域边界划分 | 第 7 章 |

## D.2 算法术语的资源含义速查表

> 用法:每行一句话只回答"这个词落在哪笔资源上"。完整机制与量化公式请到"定义章节"列所指位置,本表不替代正文(单点定义原则见公共前置说明)。

### D.2.1 模型与结构

|---|---|---|

| 激活值(Activations) | 前向传播的中间结果,反向必须保留,是训练显存峰值的主要来源,可用重计算换算力 | [§3.1](../第一部分-基础与心智模型/第03章-人工智能与大模型基础.md#31-神经网络与训练三阶段) |
| 梯度(Gradients) | 反向阶段产生的与参数同形状的显存,并触发 DP 域的每步通信 | [§3.1](../第一部分-基础与心智模型/第03章-人工智能与大模型基础.md#31-神经网络与训练三阶段) / 第 7 章 |
| 优化器状态(Optimizer States) | 每参数额外字节数的放大器,决定训练显存下限,是 ZeRO 分片的对象 | [§3.2](../第一部分-基础与心智模型/第03章-人工智能与大模型基础.md#32-优化器与超参的-infra-含义) / 第 17 章 |
