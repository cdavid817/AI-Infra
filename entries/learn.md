# 学习原理

**适用角色**:想建立 AI Infra 系统知识模型的平台工程师、方案与选型方,以及没有算法背景的新人。

**能解决的问题**:某个机制为什么存在、内部如何工作、边界在哪里;算法概念如何转译成资源事实。

## 从哪里开始

- **完整目录与阅读路径**:[README 目录](../README.md)——31 章正文 + 7 个附录,并附「我想做的事 → 读哪几章」任务索引
- **零基础**:第 1 → 2 → 3 章建立全局认知;无算法背景先读第 3 章、第 6 章
- **横切概念单点定义**:精度格式(§4.3)、Roofline(§4.4)、profiling(§5.4)、显存换算(§6.2)、互联域(第 7 章)等,入口见 [README 写作纪律速记](../README.md#写作纪律速记)

## 学完之后

- 想动手验证机制 → [动手实验](labs.md)(没有环境也可以,见 [零环境路径](../labs/no-environment.md))
- 想把知识用于选型与容量 → [架构决策](decide.md)
- 想核验书中结论的证据 → [证据与更新](evidence.md)
