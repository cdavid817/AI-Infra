# ADR-002:任务型五入口信息架构

- 状态:已采纳(2026-09)
- 规范:[governance/content-architecture.md](../governance/content-architecture.md)

## 背景

仓库内容已覆盖 31 章正文、11 个 Labs、12 个 Runbooks、7 档参考架构、7 个计算器和 Claim 证据登记,但站点导航只有按部/章的线性目录。带着具体任务来的读者(排障、容量评估、选型)需要预先知道内容藏在哪个编号章节里,实验、Runbook、计算器和证据的可发现性差。

## 决策

在**不移动任何既有文件**的前提下,站点增加五个任务型一级入口:学习原理、动手实验、生产运维、架构决策、证据与更新。每个入口是一个轻量 Landing Page,链接既有内容;内容关系统一登记在 `book-manifest.yaml`。

## 后果

- 正文保留原编号与路径,外部链接不受影响。
- 同一资产可被多条任务路径引用,关系由 Manifest 单点维护,防止 README、侧边栏与正文关系漂移。
- 新内容合入时需要同步登记 Manifest(由 `scripts/validate-manifest.mjs` 把关路径有效性)。

## 备选方案

仅维护线性目录:实现最简单,对通读者足够,但对排障、容量评估等非线性任务型读者不友好,放弃。
