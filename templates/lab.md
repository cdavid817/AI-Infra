# Lab 模板

每个 Lab 文件开头必须有元信息表,随后按固定五节展开:

```markdown
# Lab NN:<标题>

| 项 | 值 |
|---|---|
| 等级 | L0 无 GPU / L1 单 GPU / L2 单机多 GPU / L3 集群(K8s/Slurm) |
| 预计资源与成本 | <卡数×时长量级;成本敏感处显式警示> |
| 安全风险 | <无 / 具体风险与边界(如出网、特权)> |
| 关联章节 | <书内章节与公式引用> |

## 目标
<做完能回答什么问题;与章节交付物呼应>

## 步骤
<可执行流程;写工具名与通用命令形态,不锁版本号;涉及数字预期只给可推导的量级并引用书内公式>

## 成功判据
<可验证:测得什么、算得什么、与哪个公式/结论对得上>

## 清理步骤
<释放资源、删除测试产物;集群级 Lab 必须有>

## 常见失败与排查
<2–4 条,指向对应 Runbook 或章节>
```

纪律:不编造基准数字;"预期结果"只写方向与量级推导;成本高的步骤(千卡、长时)标注替代的缩小版做法。
