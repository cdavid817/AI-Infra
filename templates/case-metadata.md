# 案例元数据模板

每章「问题场景」标题后紧跟以下可见元数据块(四选一填写,删除不适用行):

```markdown
> **案例元数据**
> - **案例类型**:公开真实案例 / 作者实测案例 / 合成案例 / 容量估算示例
> - **数据性质**:官方数据 / 公开实测 / 作者实测 / 推导 / 示意
> - **来源或复现**:`CLM-0XX-XXX`、公开链接或 `labs/...`;合成案例写「无(见声明)」
> - **适用边界**:硬件、软件、时间、负载或组织前提
> - **声明**:(合成案例必填)人物、机构、日期与数值均为写作构造的示意,用于说明方法,不构成真实事故记录
```

规则:

- **公开真实案例**必须有来源(`CLM` 指向含 L1/L2 来源的 claim)。
- **作者实测案例**必须有复现路径(`labs/...`)。
- **合成案例**必须包含声明行。
- **容量估算示例**必须在对应 claim 的 `estimate` 字段列出输入、公式、假设和误差来源。
